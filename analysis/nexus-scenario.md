# سناریوی نهایی «هسته / Nexus» — سند مرجع طراحی
> نسخه ۲ — پس از بازخورد مالک: «بکگراد شلوغ شده، همه‌چیز درهم است؛ باید تفکیک کنی و رنگ‌ها متمایز باشند.»
> روش‌شناسی: منطق design-token (همان اصل awesome-design-systems: هر رنگ دقیقاً یک نقش) + shadcn/ui برای UI.

---

## ۱. خط داستانی (Scenario — سه پرده)

**پردهٔ صفر — دنیای بیرون (تفکیک سخت):**
سایت عادی با پس‌زمینهٔ تم خودش می‌ماند. «دنیا» یک **تابلوی محصور** است، نه یک پس‌زمینهٔ سراسری.
دنیای Nexus فقط داخل قاب خودش وجود دارد؛ هیچ‌وقت پشت hero یا بخش‌های دیگر نمی‌آید.
(رفع باگ: قبلاً canvas فلکس سراسری + ThemeBackground روی هم چیده شده بودند = درهم‌ریختگی.)

**پردهٔ اول — نقشهٔ ساکت (Calm Map):**
داخل قاب: زمینهٔ مرکب تیره، خطوط کانتور طلایی مثل نقشهٔ فنی که آرام نفس می‌کشند.
شش «منطقهٔ رنگی» — هر رشته یک محله با رنگ اختصاصی خودش: ذره‌های هم‌رنگ دور گره خودش
می‌مانند (چاه نور + هالهٔ محلی). رنگ‌ها **متمایز و جداشده**اند، نه مخلوط.

**پردهٔ دوم — نیروی خارجی (Mouse as Force):**
موس داخل قاب = مشعل و دافعه: کانتورها زیر نور روشن می‌شوند، ذره‌های همان محله پس می‌زنند و
می‌چرخند. موس بیرون قاب = هیچ اثری روی دنیا ندارد (مرز واقعی است).

**پردهٔ سوم — جوشش (The Forge):**
عبور از دو رشته در <۷ ثانیه = قوس گرادیانی دو رنگ از محله‌ای به محلهٔ دیگر + کارت سنتز
با نام یک امکان واقعی. رنگ قوس فقط دو سرش معنا دارد (رنگ دو رشته) — هستهٔ سفید طلایی وسط.

## ۲. توکن‌های رنگ (هر رنگ = یک نقش — قانون سخت)

| توکن | مقدار | نقش | کجا ممنوع |
|---|---|---|---|
| `--nx-ink` | `#05060a` | زمینهٔ دنیا (مرکب) | هرجای بیرون قاب |
| `--nx-gold` | `hsl(38 …)` | خطوط ساختاری + رشتهٔ مهندسی | رنگ‌پاشی عمومی |
| مهندسی | `38°` کهربایی | گره/ذره/هالهٔ مهندسی | — |
| ریاضی | `265°` بنفش | فقط محلهٔ ریاضی | — |
| فیزیک | `182°` فیروزه‌ای | فقط محلهٔ فیزیک | — |
| شیمی | `132°` سبز | فقط محلهٔ شیمی | — |
| دیجیتال | `320°` سرخابی | فقط محلهٔ دیجیتال | — |
| طراحی | `8°` سرخ | فقط محلهٔ طراحی | — |
| `--nx-spark` | `#ffe9c4` | هستهٔ قوس جوشش | ذرات عادی |

قوانین: ① فاصلهٔ hueها ≥ ۴۵°؛ ② رنگ هر رشته فقط در شعاع محلهٔ خودش دیده می‌شود
(چاه نور نمایی با شعاع محدود)؛ ③ نشتی tint سراسری ≈ صفر؛ ④ بیرون قاب = سیستم رنگ
سایت (shadcn tokens)، بدون آمیختن با دنیا.

## ۳. قوانین صحنه (تفکیک)

1. قاب: `rounded-3xl` + حاشیه + `overflow-hidden` — دنیا یک پنجره است.
2. تراکم: ذرات ~۵.۲k دسکتاپ / ~۲.۴k موبایل (قبلاً ۹k)؛ هر خوشه با فنر محکم به گره خودش
   و سقف شعاع محله (~۳۰۰px) — رنگ‌ها قلمرو دارند.
3. هدر/راهنما/پایپ‌لاین روی زمینهٔ تیرهٔ خودِ پنل، بیرون از قاب صحنه.
4. Reduced-motion: یک نقاشی ثابت؛ بدون WebGL2: گرادیان استاتیک؛ سقوط کیفیت: نردبان DPR.
5. تعهد مالک: تا تأیید صریح، هیچ‌چیز به پروداکشن نمی‌رود؛ اگر نشد، سایت قبلی به قوت خودش است.

## SCENARIO v3 — «نقشهٔ تمیز / Clean Map» (بازخورد مالک: «هنوز شلوغ است؛ رنگ‌ها قاطی‌اند»)

ریشهٔ شلوغی در v2 (تأیید با اسکرین‌شات مرورگر):
1. `fbm(...)*0.75` وارپ سنگین → خطوط کانتور چاقِ کرمی‌شکل («کرم‌های گلی») روی کل صحنه
2. `lineCol += tint*1.15` → رنگ هر رشته سوار خطوط می‌شد و در فاصلهٔ بین دو گره قاطی می‌شد (زیتونی/قهوه‌ای/ماوِه)
3. `wells*2.2` جمع ۶ چاه → هرجای بین گره‌ها دوبرابر روشن؛ سوپ افزودِی
4. گرید + مقیاس دوم خطوط + wash سراسری tint = سیستم‌های هم‌زمان زیاد

قانون v3 — «هر نقش، یک سیستمِ ترسیمی؛ هر رنگ، یک محله»:
- کاغذ نقشه: خط کانتور تِک‌مقیاس نازک (0.016) با جوهر خنثی گرم — رنگ هرگز سوار خط نمی‌شود
- رنگ: فقط کفِ محلهٔ هر گره، گاوسِین سخت (exp(-d²·30)، شعاع ≈۱۴۰px) — هیچ هم‌پوشانی
- ذرات: ۵.۲k→۳k دسکتاپ / ۲.۴k→۱.۴k موبایل، hue قفل روی محله (wobble 0.02→0.007)
- فنر محله محکم‌تر (0.0016) + سقف سخت (pull 0.075) — رنگ به قلمروی همسایه نشت نمی‌کند
- گرید 0.045→0.026، wash سراسری حذف، مشعل ملایم‌تر (exp(-d·4))
- hero: بلاب‌های محلی حذف شد — مالکِ فضای سایت فقط ThemeBackground (یک لایه، نه دو)
- hueها بازچینش با بیشینه فاصلهٔ چرخ: مهندسی ۴۰ / ریاضی ۲۵۰ / فیزیک ۱۷۵ / شیمی ۱۰۵ / دیجیتال ۳۱۰ / طراحی ۳۵۵

## SCENARIO v4 — «شفق / Aurora Sky» (حکم مالک دربارهٔ v3: «اصلا خوب نیست» — تغییر گرافیک، بکگراند و سناریو)

تشخیص: نقشهٔ فنی v3 «درست» بود ولی سرد و بی‌روح — زیباییِ نتیجه نمی‌داد. سناریو عوض شد، نه فقط تنظیم.

مفهوم: آسمان شبِ زنده — سه پردهٔ شفق واقعی (WebGL fbm: بنفش→فوشیا با لبِ روشن و رگه‌های عمودی + زمزمهٔ کهربایی)، غبار اخگری صعودکننده (~۶۴۰ دسکتاپ / ~۳۲۰ موبایل، بوکهٔ additive)، ستاره‌های چشمک‌زن، درخشش افق. شش رشتهٔ مهرداد = ستاره‌های صورت فلکی با خطوط منتظرِ از قبل کشیده‌شده. عبور از دو ستاره = قوس نورانی + کارت سنتز (همان مکانیک معنایی: دو رشتهٔ متفاوت → امکان واقعی).

قوانین رنگ v4: یک آسمان، یک روایت — بنفش/فوشیا/کهربایی مارک؛ ستاره‌ها رنگ ملایم خودشان را دارند (۴۲ طلایی، ۲۶۲ بنفش، ۱۹۵ فیروزه‌ای، ۱۵۰ زمردی، ۳۱۵ فوشیا، ۳۴۵ رز) ولی کل صحنه با شفق هم‌خانواده است.

فنی: AuroraEngine.ts (SKY_FS + DUST points، DPR ladder، IO/تب-مخفی، reduced-motion = یک فریم ثابت، stage-contained، پارالاکس سه‌لایه u_par + CSS var --au-par-*)؛ AuroraPrototype.tsx (صورت فلکی DOM، خطوط منتظر SVG که با هاور گرم می‌شوند، قوس گرادیانی، کارت شیشه‌ای، نوار پایپ‌لاین)؛ داده از nexusData.ts (یک منبع حقیقت). فیکس باگ stale-closure: فراخوانی forge از طریق touchRef همیشه‌تازه.
