## ۲. تصمیم اصلی: «۳ لمس در روز» به‌جای «۳ پست در روز»

پیشنهاد مالک: ۳ پست در روز (یکی دعوت به همکاری، یکی آموزشی، یکی سفارش/معرفی پروژه).

**ساختار سه‌محوری درست است و پذیرفته شد؛ فرکانس ۳ پست/روز نه.** دلایل:

1. **اشباع تبلیغاتی**: دو محور از سه محور «درخواست» است (همکاری + سفارش). با ۳ پست/روز حدود ۶۶٪ محتوا خودتبلیغی می‌شود — برخلاف قاعدهٔ ۸۰/۲۰ (۸۰٪ ارزش، ۲۰٪ درخواست). نتیجه: رشد صفر با هزینهٔ دوبرابر.
2. **سابقهٔ ناپوستینی**: کل عمر پیج ۹ پست است و یک وقفهٔ ۲۰ ماهه دیده. پرش ناگهانی به ۴۲ پست در ۱۴ روز الگوی burnout قبلی را تکرار می‌کند.
3. **توصیهٔ خود Composio**: ۴ تا ۵ ریل در هفته + هر پست با سؤال/CTA پایانی.
4. **رفع ابهام نیچ**: مسیر قفل‌شده = «ساخت محصول با هوش مصنوعی برای استارتاپ‌ها» — هر محتوایی بیرون از این دایره (ورزش/بازی/… ) پست نمی‌شود.

## ۱۰. وضعیت اتوماسیون (Composio)

**آماده است (D-059):** محتوا + تصویر + دکمهٔ «کمپین ۱۴ روزه» در استودیو + انتشار دو مرحله‌ای Meta (media container → publish) + انتشار خودکار روزانه یک پست از کرون صبحگاهی ۰۵:۳۰ تهران.

**مانده از مالک (تنها ۲ اعتبارنامه):**
1. `COMPOSIO_API_KEY` — از dashboard.composio.dev → API Keys
2. `COMPOSIO_INSTAGRAM_CONNECTED_ACCOUNT_ID` — شناسهٔ اتصال اینستاگرام در همان داشبورد

تحلیل Composio که خود مالک گرفت (پروفایل + اینسایت ۳۰ روزه) اثبات کرد اتصال اینستاگرام او سطح Graph است (اینسایت فقط با اکانت Business/Creator می‌آید) — پس فقط کلید مانده.

**بعد از ست‌شدن:** پست‌های فید خودکار منتشر می‌شوند؛ استوری‌ها با API رسمی اینستاگرام قابل انتشار نیستند و طبق اسکریپت بخش ۶ دستی گذاشته می‌شوند (چیزی که از مالک فقط ۵ دقیقه در روز می‌خواهد).

### ۱۱.۳ صداگذاری — وضعیت و مسیر پیش‌رو

- **تست TTS انجام شد:** صداهای فعلی سرویس، فارسی را قابل استفاده نمی‌خوانند (راستی‌آزمایی با چرخهٔ TTS→ASR: انگلیسی کامل برگشت؛ فارسی مخدوش) → فرمت فعلی «متن-محور با موسیقی» است که خودش یک فرمت اثبات‌شدهٔ ریل آموزشی است
- **ارتقای اصیل‌تر:** صدای خود مالک روی همین قالب (روی صحنه‌ها با موبایل ضبط شود؛ موسیقی زیرش می‌آید) — برای پرسونال‌برند بهترین گزینه است
- **موسیقی ترند اینستاگرام:** با API قابل الصاق نیست — پست‌هایی که می‌خواهند با آدیوی ترند بروند باید دستی از اپ منتشر شوند؛ ریل‌های خودکار با موسیقی جاسازی‌شده می‌روند (بدون مشکل کپی‌رایت چون سینت‌شدهٔ اختصاصی است)
